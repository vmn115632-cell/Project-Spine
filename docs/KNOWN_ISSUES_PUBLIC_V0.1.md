# 已知问题（v0.1）

> 适用版本：`0.1.0-rc.1`

当前没有已知的发布阻塞问题。以下项目属于已确认的非阻塞限制。

## 1. Windows 安装包未签名

### 现象

当前 Installer、应用程序和卸载程序尚未进行 Authenticode 代码签名。Windows SmartScreen 或部分安全软件可能显示“未知发布者”或要求额外确认。

### 影响

这会增加首次安装的确认步骤，也意味着 Windows 无法通过受信任发布者证书验证软件身份。

### 建议

- 只从本仓库的正式 Releases 页面下载安装包；
- 在确认来源之前，不要选择继续运行；
- 不建议为了安装而关闭 Windows 安全功能。

有关 SmartScreen 的操作说明，请参阅[安装说明](./INSTALL_GUIDE.md)。

## 2. 大型项目 Canvas 初始总览文字较小

### 现象

当项目包含较多节点时，Canvas 为了在初始视图中呈现完整结构，会采用较小的整体缩放比例。在 97 个节点规模的项目中，初始总览不适合直接阅读所有节点文字。

### 影响

用户需要缩放或平移后阅读局部节点。项目关系、当前节点和状态仍可显示，Tree View 仍是查看和维护详细结构的主要入口。

### 当前处理

这是视觉可读性限制，不影响项目数据、节点编辑、Mini 模式或主要使用流程。后续版本会继续评估大型画布的浏览体验。

## 3. 当前产品边界

以下内容是 v0.1 的明确范围，不属于缺陷：

- **本地优先、单用户**：当前不包含账号系统、云同步、团队协作或复杂权限；
- **Windows x64**：当前没有提供 macOS 或 Linux 版本；
- **Blueprint 导入**：当前用于创建新项目，不支持合并到已有项目或替换部分子树；
- **Mini 的职责**：Mini 提供浏览和少量高频操作，完整结构编辑仍在主界面完成；
- **自动化能力**：当前不包含 AI 自动生成结构、自动规划或公开模板市场；
- **卸载策略**：普通卸载默认保留应用用户数据，因此不会自动释放项目数据和备份占用的空间。
