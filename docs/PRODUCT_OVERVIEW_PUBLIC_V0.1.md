# Project Spine 产品概览

## 1. Project Spine 是什么

Project Spine 是一个面向长期复杂项目的本地桌面应用，用来建立、查看并持续维护清晰的项目脉络。

它不是普通的待办事项工具。Project Spine 关注的是项目由哪些阶段、模块、任务和决策组成，当前正在推进哪个节点，以及在多次工作会话和长期执行中，如何保留必要的上下文。

## 2. 要解决的问题

长期项目经常面临这些困难：

- 项目持续时间越长，最初的结构和目标越容易被日常执行淹没。
- 聊天记录、零散文档和临时笔记会逐渐分散，很难快速找回当前上下文。
- 常规任务工具可以记录待办事项，却不容易表达阶段、分支、决策及其层级关系。
- 从规划切换到执行后，用户往往知道“还有很多事”，却不清楚项目现在具体位于哪里。

Project Spine 通过一套持续可见的项目结构，把整体路线、当前路径和节点信息放在同一个工作空间中。

## 3. 核心设计理念

### 项目脉络持续可见

项目以树形结构组织。阶段、模块、任务和决策之间的关系不会因为一次对话结束或文档关闭而消失。

### 当前节点明确

每个项目最多只有一个当前节点。用户可以同时看到项目的全局结构、当前阶段、当前路径和正在执行的位置。

### Main 与 Mini 分工协作

主界面用于查看整体结构、编辑节点和维护详细信息；Mini 模式适合长期停留在桌面侧边，持续显示项目主脉络和当前位置，并提供少量高频操作。两个界面使用同一份项目数据并保持同步。

### Blueprint 快速建立结构

结构化 Blueprint 可以先经过校验和预览，再导入为一个新项目。它适合将已经整理好的项目框架快速落入 Project Spine，而不需要逐个手工创建节点。

## 4. 主要功能

### 项目中心

创建和打开本地项目，并查看项目进度、当前节点和最后更新时间。

### 项目脉络树与画布视图

树形视图用于浏览和维护项目层级；画布视图使用同一份节点数据，从另一种角度展示项目结构与关系。

### 节点系统与详情编辑

支持阶段、模块、任务和决策节点。节点可以记录状态、目标、任务清单、关键产出、完成标准和备注，并支持设置唯一的当前节点。

### Blueprint 导入

支持选择 JSON Blueprint，完成结构校验、预览和确认后导入为新项目。

### Mini 模式

用轻量窗口展示项目阶段、当前路径和当前节点。Mini 会保留项目主脉络，同时突出当前执行位置，适合在工作过程中长期查看。

### Mini Quick Actions

可以在 Mini 中完成或取消任务清单项目、更新允许的节点状态，并记录简短备注。修改会与主界面同步。

### 本地持久化与恢复

项目数据保存在本地 SQLite 数据库中。应用支持数据库迁移、备份、启动健康检查和恢复流程，也会保存常用的界面状态，例如选择节点、展开路径和窗口显示状态。

## 5. 适合谁使用

Project Spine 更适合需要持续维护结构和上下文的个人项目，例如：

- 跨越数周或数月的个人产品与研发项目；
- 有明确阶段、分支和产出的复杂学习计划；
- 研究、写作、内容制作或独立创作项目；
- 需要同时关注整体路线和当前执行节点的长期任务。

如果需求只是记录少量临时待办，普通任务清单通常会更直接。

## 6. 当前版本

当前公开候选版本为 `0.1.0-rc.1`，面向 Windows x64。

这一版本已经覆盖从建立项目结构、日常推进到本地持久化和恢复的完整使用链路，可用于真实个人项目。当前仍有少量非阻塞限制，包括未签名的 Windows 安装包，以及大型项目在画布初始总览时文字较小。详情请参阅[已知问题](./KNOWN_ISSUES_PUBLIC_V0.1.md)。
