# Project Spine v0.1 Release Notes

> 当前候选版本：`0.1.0-rc.1`  
> 平台：Windows x64

## 1. 版本定位

Project Spine v0.1 是第一个可安装、可分享并可用于真实长期项目的公开候选版本。

本版本完成了从项目结构建立、当前节点定位、Main 与 Mini 协同，到本地数据持久化、备份和恢复的主要闭环。它面向个人长期复杂项目，不以通用待办清单或团队项目管理平台为目标。

## 2. 本版本已包含

### 项目中心

- 创建和打开本地项目；
- 显示项目进度、当前节点和最近更新时间；
- 支持项目完成、归档及相应生命周期管理。

### 项目脉络与节点系统

- 使用阶段、模块、任务和决策节点表达项目结构；
- Tree View 用于浏览和维护层级；
- Canvas View 用于查看同一份项目数据的可视化关系；
- 支持节点创建、编辑、删除、排序、状态和唯一当前节点。

### 节点详情

- 编辑节点目标、任务清单、关键产出、完成标准和备注；
- 在项目结构与执行细节之间保持清晰对应。

### Blueprint 导入

- 从 JSON 文件导入结构化项目蓝图；
- 导入前提供格式、层级和节点类型校验；
- 通过预览确认后创建新项目。

### Mini 模式

- 以轻量窗口持续显示项目阶段、当前路径和当前节点；
- 支持三档窗口尺寸；
- Mini Quick Actions 支持任务清单、节点状态和简短备注操作；
- Main 与 Mini 共享同一份项目数据并实时同步。

### 本地数据能力

- 使用 SQLite 保存项目和节点数据；
- 支持有序数据库迁移；
- 支持自动备份、启动健康检查和恢复流程；
- 保存选择节点、展开状态、滚动位置和窗口状态等界面信息；
- 普通卸载默认保留用户项目数据。

### Windows 交付

- 提供 Windows x64 Installer；
- 应用、安装程序、快捷方式和窗口使用统一的 Project Spine 名称与图标。

## 3. 稳定性说明

发布候选版已经完成自动化检查、生产构建、全新安装、重启恢复、卸载与重装验证。

验收中使用了一个包含 97 个节点、9 个阶段、最大深度为 4 的真实项目 Blueprint，完整验证了：

- Blueprint 校验、预览和导入；
- Main 与 Mini 浏览及轻量操作；
- 项目数据与界面状态在退出、重启后的恢复；
- SQLite、备份和恢复启动流程；
- Windows 安装、卸载和保留数据后的重装。

最终回归包含 73 项自动化测试，并通过 TypeScript 检查、生产构建和安装包验证。当前没有已知的发布阻塞问题。

## 4. 非阻塞限制

- Windows 安装包尚未进行代码签名，可能触发 SmartScreen 或显示“未知发布者”；
- 大型项目在 Canvas 初始全局适配时缩放较小，阅读节点文字通常需要进一步缩放或平移。

更多说明请参阅[已知问题](./KNOWN_ISSUES_PUBLIC_V0.1.md)。

## 5. 后续方向

后续版本将继续聚焦长期项目的实际使用体验，包括：

- 优化公开安装、说明和首次使用体验；
- 持续打磨 Mini 长期常驻和 Main/Mini 协同细节；
- 改善大型项目的浏览和结构展示；
- 探索更完善的结构化导入与项目上下文表达能力。

这些方向不代表已承诺的版本功能，仍需经过独立评审后决定是否实施。
