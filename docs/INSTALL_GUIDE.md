# Project Spine 安装说明

## 1. 系统要求

- Windows x64 桌面环境；
- 建议使用仍在获得安全更新的 Windows 版本；
- 安装和项目数据需要一定的本地磁盘空间；
- Project Spine 是本地桌面应用，核心功能不依赖云端账号。

当前版本尚未提供 macOS 或 Linux 安装包。

## 2. 获取安装包

Project Spine 安装包将通过本仓库的 **Releases** 页面提供。

请从正式 Release 条目下载 Windows Installer，不要使用来源不明的转载文件。当前候选版本的安装包名称为：

`Project-Spine-Setup-0.1.0-rc.1.exe`

## 3. 安装步骤

1. 从本仓库 Releases 页面下载 Windows 安装包。
2. 关闭旧版本的 Project Spine 窗口。
3. 双击安装包并等待安装完成。
4. 安装完成后，从桌面快捷方式或开始菜单启动 Project Spine。

### 如果 Windows SmartScreen 显示提示

当前安装包未进行 Authenticode 代码签名，因此 Windows SmartScreen 可能显示“Windows 已保护你的电脑”或“未知发布者”。这不代表系统已经验证安装包安全，也不应通过关闭系统安全功能来绕过提示。

如果你确认文件来自本仓库的正式 Releases 页面，并愿意接受未签名软件的运行风险，可以：

1. 在 SmartScreen 提示中选择“更多信息”；
2. 核对应用名称；
3. 选择“仍要运行”。

如果无法确认下载来源，请取消安装并删除该文件。

## 4. 首次使用建议

启动后会进入项目中心。你可以选择以下方式开始：

- **创建空项目**：适合从零开始建立项目结构；
- **导入 Blueprint**：适合已有结构化项目蓝图的情况，导入前会显示校验和预览结果。

建议先在主界面查看完整项目结构，设置当前节点并补充节点目标。进入长期执行阶段后，可以打开 Mini 模式，将项目主脉络和当前位置保留在桌面侧边。

## 5. 卸载说明

可以通过 Windows 的“已安装的应用”界面卸载 Project Spine。

当前卸载策略是：**删除应用程序，但默认保留用户数据**。项目数据库、备份和工作区状态不会随普通卸载自动删除，以降低误删长期项目数据的风险。重新安装后，应用可以继续读取保留的数据。

如果确实需要完全清理，请先确认不再需要任何项目和备份，再手动删除 Project Spine 的应用用户数据目录。该操作不可通过普通卸载恢复，建议先自行备份重要内容。

## 6. 注意事项

- 当前 Windows 安装包未签名，可能触发 SmartScreen 或第三方安全软件提示；
- 当前版本为本地优先、单用户应用；
- 当前不提供云同步、账号登录或团队协作；
- 卸载默认保留用户数据，因此不会自动释放这部分磁盘空间；
- 安装新版本前，建议正常关闭正在运行的 Project Spine。
