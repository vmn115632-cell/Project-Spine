# Project Spine 安装说明

## 1. 系统要求

- Windows x64 桌面环境；
- 建议使用仍在获得安全更新的 Windows 版本；
- 安装程序和项目数据需要足够的本地磁盘空间；
- Project Spine 是本地桌面应用，核心功能不依赖云端账号。

当前版本尚未提供 macOS 或 Linux 安装包。

## 2. 获取安装包

请从本仓库正式 Releases 页面下载：

`Project-Spine-Setup-0.2.0-rc.1.exe`

文件大小：`123,360,429 bytes`

SHA-256：`44C904089913C52FBB4351B80168C43C75DA66C18CE46C892887DBDCE0594973`

不要使用来源不明的转载文件。

## 3. 安装步骤

1. 下载 Windows Installer；
2. 关闭已运行的 Project Spine 窗口；
3. 运行安装程序；
4. 在安装向导中确认或选择软件安装目录；
5. 安装完成后，从桌面快捷方式或开始菜单启动 Project Spine。

V0.2 支持自定义软件安装目录。软件程序位置和业务数据位置是两个独立选项，改变安装目录不会自动移动项目数据。

### Windows SmartScreen 提示

当前 Installer 尚未进行 Authenticode 代码签名，因此 Windows SmartScreen 可能显示“Windows 已保护你的电脑”或“未知发布者”。

如果你确认文件来自本仓库正式 Releases 页面，并愿意接受未签名软件的运行风险，可以选择“更多信息”，核对应用名称后再决定是否运行。如果无法确认来源，请取消安装。

## 4. 首次启动

V0.2 默认进入 Mini Workspace。没有项目时，可以从 Mini 打开 Main，创建项目或导入 Blueprint。

建议先在 Main 中确认完整项目结构和当前节点，再回到 Mini 进行日常推进。

## 5. 自定义数据目录

Project Spine 支持选择主要项目数据的保存位置。你可以从应用内的“数据位置”入口查看当前位置，并按界面提示迁移到新的目录。

迁移前建议：

- 正常关闭其他 Project Spine 窗口；
- 确保目标磁盘有足够空间并保持连接；
- 为重要项目数据保留独立备份；
- 迁移过程中不要强制结束应用。

主要 Project Spine 项目数据可以存放到用户选择的位置。Windows 与应用运行框架仍可能在系统用户目录保存少量运行配置或缓存，因此不承诺完全不使用系统盘。

## 6. 卸载说明

可以通过 Windows 的“已安装的应用”卸载 Project Spine。

普通卸载会移除应用程序，但默认保留业务数据，以降低误删长期项目的风险。重新安装后，可以继续使用保留的数据或在应用内选择对应的数据位置。

如果确实需要完全清理，请先确认不再需要任何项目，并自行保留必要备份后再手动处理数据目录。

## 7. 升级注意事项

- 当前版本是 Release Candidate，不是 Stable；
- V0.1 到 V0.2 的完整覆盖升级场景尚未全部覆盖；
- 升级前请关闭应用并备份重要项目数据；
- 安装新版本后，先确认项目列表、当前节点和数据位置正常。
