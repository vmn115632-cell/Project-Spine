# Project Spine v0.1.0-rc.1

## About

Project Spine is a Windows desktop application for keeping the structure, current position, and execution context of long-term complex projects continuously visible.

## Highlights

- Project Spine workspace
- Blueprint Import
- Mini Mode
- Main / Mini synchronization
- Local persistence
- Backup and Recovery

## Installation

The Windows installer is available in the Assets section below. Read the installation guide before running the installer.

## Known Issues

- The Windows installer is unsigned and may trigger Windows SmartScreen.
- Text may appear small in the initial overview of a large canvas; zoom or pan to inspect individual nodes.
