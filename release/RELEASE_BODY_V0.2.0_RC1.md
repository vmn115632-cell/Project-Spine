# Project Spine v0.2.0-rc.1

## 本次更新

V0.2 重点提升 Mini 的日常使用体验，并补全数据位置控制和项目生命周期能力。

## 主要更新

### Mini Workspace

- 默认以 Mini 作为工作入口
- 快速切换项目
- 快速修改 Task 状态
- Pin / 最小化 / 关闭行为优化
- Main 与 Mini 切换优化
- Quick Note 支持查看最近记录

### 项目管理

- 支持编辑项目名称与描述
- 新增项目删除

### 数据与安装

- 自定义安装目录
- 自定义数据保存位置
- 数据目录迁移

### 性能与稳定性

- 优化较大项目下的 Mini 状态更新
- 减少界面阻塞
- 改善 Windows 窗口恢复和生命周期

### AI Blueprint

AI Blueprint Generation 继续可用，Blueprint Schema 仍为 `0.1`。
